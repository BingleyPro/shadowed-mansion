# Shadowed Mansion
A WIP Godot game! If you like to preview this and the features in Godot, **clone** the repository or download a zip (https://github.com/BingleyPro/shadowed-mansion/archive/refs/heads/main.zip) and extract into an empty folder. Then, open up any Godot 4 version and select the folder with the project files.
